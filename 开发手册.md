## Windows

## 打包

1. 运行windows.ps1下载依赖
2. 运行"npm run windows"打包

## 升级yt-dlp.exe

./yt-dlp.exe -U

## 配置存储的位置

%APPDATA%\ytdownloader\Local Storage

大概率是：C:\Users\<你的用户名>\AppData\Roaming\ytdownloader\Local Storage

## Linux

执行./linux.sh下载依赖

Linux下打包Windows：

docker run --rm -v $(pwd):/project electronuserland/builder:wine bash -c "cd /project && npm run windows"

打包Linux:

npm run linux
